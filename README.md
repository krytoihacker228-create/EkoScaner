# EkoScaner

## Описание
Этот репозиторий содержит код на языке программирования Python для нейросетевой модели, созданная для соревнования "Хакатон", которая с точностью более 50% определяет одну из пяти категорий мусора по фотографии.
На данный момент программа разделяет мусор на 5 классов: пластик, органика, стекло, метал и бумага.

В программе была использована свёрточная нейросеть SimpleNN.

## Датабаза
Для создания использовалась датабаза "Garbage Image Test" по ссылке https://www.kaggle.com/datasets/farzadnekouei/trash-type-image-dataset
